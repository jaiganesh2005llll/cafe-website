# Brew & Bloom Café – free static website theme

Plain HTML/CSS/JS. No build step.

## Deploy with GitHub + Vercel
1. Create a new GitHub repo and upload everything in this folder (unzipped) to the repo root.
2. Go to vercel.com > Add New > Project > import the repo.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty. Click Deploy.

## Customize
- Text and contact details: `index.html`
- Menu items and prices: top of `script.js`
- Colors and fonts: `:root` variables in `style.css`

Free to use and modify for any project.
